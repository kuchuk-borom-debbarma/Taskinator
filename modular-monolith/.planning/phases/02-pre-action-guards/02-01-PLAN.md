<task type="auto">
  <name>Task 1: Implement Guard Queries and Service logic</name>
  <files>
    src/modules/task/internal/GuardQueries.ts,
    src/modules/task/internal/GuardService.ts
  </files>
  <action>
    1. Create `src/modules/task/internal/GuardQueries.ts`:
       - `checkActiveSubtasks(taskId: string)`: Query `task_reachability` joined with `project_task` where `ancestor_task_id = taskId` and descendant status is NOT 'COMPLETE'.
       - `checkIncompleteBlockers(taskId: string)`: Query `task_link` joined with `project_task` where `target_task_id = taskId`, label is 'blocks', and source status is NOT 'COMPLETE'.
       - `checkTeamAssignment(taskId: string)`: Query `project_task` to check if `fk_team_id` is null for the given taskId.
    2. Create `src/modules/task/internal/GuardService.ts`:
       - Define `GuardService` class.
       - Implement `evaluateGuards(action: 'update' | 'delete', param: any)`:
         - Fetch active rules for the project from `behavior_rule` table.
         - For each rule:
           - If `PARENT_DELETE_GUARD` and action is 'delete', call `checkActiveSubtasks`.
           - If `BLOCKER_SAFETY_GUARD` and action is 'update' with status 'IN_PROGRESS', call `checkIncompleteBlockers`.
           - If `MEMBER_ASSIGNMENT_GUARD` and action is 'update' with `memberId` change, call `checkTeamAssignment`.
         - If any guard fails, throw `ValidationError` from `src/graphql/errors.ts` using the `action_message` from the rule.
  </action>
  <verify>
    <automated>npm run build</automated>
  </verify>
  <done>Guard logic implemented and type-safe.</done>
</task>
