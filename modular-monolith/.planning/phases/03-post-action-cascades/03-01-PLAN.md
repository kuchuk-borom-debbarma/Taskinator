<task type="auto">
  <name>Task 1: Implement CascadeService logic</name>
  <files>src/modules/task/internal/CascadeService.ts</files>
  <action>
    Create src/modules/task/internal/CascadeService.ts. 
    Implement the following methods:
    - `resolveBlockers(param: { actorId: string, traceId?: string, taskId: string, targetStatus: string })`: 
      - Find parent tasks linked via 'BLOCKER' label in `task_link` where the current task is the source.
      - For each parent, check if ALL other blockers are complete (status = 'DONE').
      - If all are complete, update parent status to `targetStatus` (e.g., 'READY').
    - `cascadePriority(param: { actorId: string, traceId?: string, taskId: string, priority: number })`:
      - Find all descendants via `task_reachability` (where depth > 0).
      - Perform a bulk update of their priority in `project_task`.
      - CRITICAL: Add `WHERE priority != ${priority}` to prevent redundant updates and event loops.
    - `cascadeTeam(param: { actorId: string, traceId?: string, taskId: string, teamId: string | null })`:
      - Find all descendants via `task_reachability`.
      - Perform a bulk update of their `fk_team_id`.
      - CRITICAL: Add `WHERE fk_team_id IS DISTINCT FROM ${teamId}` to prevent loops.
    - `cascadeDelete(param: { actorId: string, traceId?: string, taskId: string })`:
      - Find all descendants via `task_reachability`.
      - Bulk delete descendants from `project_task`.
    
    Use direct Kysely `db` for bulk operations for performance.
    Pass `actorId` and `traceId` through to maintain audit trails and trace context.
  </action>
  <verify>
    <automated>grep -E "resolveBlockers|cascadePriority|cascadeTeam|cascadeDelete" src/modules/task/internal/CascadeService.ts</automated>
  </verify>
  <done>CascadeService implemented with all 4 reactive methods using Kysely and loop prevention.</done>
