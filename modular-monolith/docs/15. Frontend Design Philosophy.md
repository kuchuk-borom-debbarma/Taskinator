# 15. Frontend Design Philosophy (Taskinator UI)

The **Taskinator** user interface is designed to be **minimal, fluent, and professional**, drawing heavy inspiration from the **Notion** aesthetic. The goal is to provide a clutter-free environment that maximizes productivity while offering powerful discovery tools.

## 1. Aesthetic Core: "Fluent Minimalism"
-   **Cleanliness**: High use of white space, subtle grays, and precise alignment.
-   **Typography**: Professional sans-serif (Inter/Outfit). Hierarchy is established through weight and scale rather than bold colors.
-   **Interaction**: Fluid transitions and subtle hover states. Components should feel "light" and responsive.
-   **Functional Icons**: Minimalist stroke-based icons (e.g., Lucide or Heroicons) used sparingly to aid navigation.

## 2. Platform Views

### A. The List View (Primary Navigation)
The default project view is a **Traditional List View**, familiar to users of major task management platforms.
-   **Structure**: A vertically stacked list of tasks with columns for Status, Team, Member, and Created Date.
-   **Efficiency**: High-density layout allowing for quick scanning and bulk updates.
-   **Filtering (Future)**: The interface is architected to support complex filtering (status, team, member, date ranges) to narrow down the task set.

### B. The Task Perspective (Detail View)
Clicking a task opens a dedicated **Perspective View** (Task Information). This view is split into logical sections:
1.  **Metadata Overlay**: Standard fields (Title, Description, Status, etc.).
2.  **Direct Links**: A section clearly listing the **Direct Incoming** and **Direct Outgoing** tasks. 
    -   Each link must show its **Label** (e.g., "Blocks", "Subtask of").
    -   This provides immediate context for the most critical dependencies.
3.  **The Neural Lattice (Radial View)**: An interactive sub-component integrated into the task information.
    -   **Scope**: Unlike the static list, the Lattice allows for deep radial discovery.
    -   **Role**: It serves as a visual "context map," letting the user explore distant ancestors and descendants without leaving the current task's perspective.

## 3. Interactive Mechanics of the Neural Lattice
Within the task perspective, the Radial View remains a powerful interactive tool:
-   **Canvas-Based**: Pannable sub-view within the task detail panel.
-   **Focus-Centric**: The current task sits at the heart of the radial layout.
-   **Expanding Reach**: The "Load More" functionality allows the user to grow the Lattice incrementally (based on depth), revealing more of the project's dependency hierarchy.

## 4. Navigation Flow
1.  **Discover**: Browse tasks in the high-efficiency **List View**.
2.  **Inspect**: Click a task to enter its **Perspective**.
3.  **Navigate Linkage**: Use the **Direct Links** for quick hops or the **Neural Lattice** for deep architectural discovery.
4.  **Re-Center**: Clicking a node in the Lattice smoothly re-centers the view onto that node, updating the metadata and direct links sections dynamically.

## 5. Mobile & Responsive Strategy
-   **Adaptive Layout**: List View transforms into a card stack on small screens.
-   **Perspective Drills**: Task Information panels occupy the full screen on mobile, with the Lattice using touch-optimized pinch-to-zoom and drag gestures.
