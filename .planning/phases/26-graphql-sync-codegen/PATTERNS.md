# Patterns: Phase 26 - GraphQL Sync & Codegen

## GraphQL Schema Patterns
- **Recursive AST**: Use Interfaces + Unions for recursive tree structures.
- **Ordered Pipelines**: Represent sequential logic as an array of Unions (`PipelineStep`).
- **Entity Agnosticism**: Triggers and conditions must accept an `EntityType` enum.

## UI Patterns
- **Codegen Hooks**: Use `useQuery` and `useMutation` with documents generated by `graphql-codegen`.
- **Fragment Masking**: Components should only receive the data they need via fragments and `useFragment`.
- **API Deprecation**: Prefer generated hooks over manual API classes for new and refactored code.
