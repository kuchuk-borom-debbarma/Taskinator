# Plan 40-01: Intra-Module Listener Decoupling Audit

## Objective

Verify that module listeners no longer own raw database or SQL logic and that intra-module write logic has been moved behind query/service boundaries.

## Tasks

1. Audit listeners in `auth`, `project`, `task`, and `team`.
2. Confirm listener files contain no direct `db`, raw SQL, or query-builder mutation calls.
3. Confirm listeners delegate event batches to the owning module service.
4. Record verification evidence for R2.

## Success Criteria

- `rg '(sql`|\.execute\(|\.update\(|\.insert\(|\.delete\(|db\.|claimEventsAtomic|import \{ db \})' modular-monolith/src/modules/*/internal/listeners` returns no matches.
- Listener files delegate to `authService`, `projectService`, `taskService`, or `teamService`.
- R2 is marked complete in milestone requirements.
