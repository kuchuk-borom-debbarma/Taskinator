# Plan 41-01: Inter-Module Listener Delegation Audit

## Objective

Verify listener write paths respect module boundaries by delegating cross-module effects through public module services rather than direct database access.

## Tasks

1. Identify cross-module listener effects in auth, project, task, and team modules.
2. Confirm listeners call the owning target module service.
3. Confirm no listener imports `db` or claim/query primitives.
4. Record R3/R4 verification evidence.

## Success Criteria

- Listener write paths delegate to service interfaces.
- No listener imports `db`, `claimEventsAtomic`, module query objects, or outbox query primitives.
- R3 and R4 have explicit phase verification evidence.
