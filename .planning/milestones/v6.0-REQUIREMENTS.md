- [x] **COND-01**: Named reusable conditions (Validated via `condition_labels`).
- [x] **COND-02**: Entity-agnostic evaluation (Validated via `ConditionEvaluator`).

- [x] **COND-05**: Composable logic (Validated via nested boolean branches).
- [x] **COND-06**: Structural hashing (Validated via SHA-256 deduplication).

### 2. Actions

- [x] **PIPE-03**: Strict semantics (Validated via halt-on-false logic).

### 4. Database Schema
- [x] **DB-01**: Conditions table (Validated).
- [x] **DB-02**: Condition labels (Validated).
- [x] **DB-03**: Actions table (Validated).
- [x] **DB-04**: Autopilots table (Validated).
- [x] **DB-05**: Autopilot steps (Validated - optimized into JSONB).

## 💡 Outcome Notes
The original requirement for a separate `autopilot_steps` table (DB-05) was adjusted during implementation to use a more performant `JSONB` column on the `autopilot` table, reducing join complexity for high-throughput scenarios.
