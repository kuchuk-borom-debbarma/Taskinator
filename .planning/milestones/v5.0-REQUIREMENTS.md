# Requirements Specification — Milestone v5.0 (Revamp Autopilot)

## 🎯 Objective
Completely tear down the existing internal Autopilot engine logic (which is crashing) while preserving the GraphQL API boundary so the UI does not break. We are not re-architecting the engine in this milestone, only safely removing the legacy core.

---

## 📋 Technical Requirements

### 1. Teardown
- **[AUTO-01]**: Safely remove `ConditionEvaluator` logic and related legacy engine files.
- **[AUTO-02]**: Safely remove `ActionHandlers` logic.
- **[AUTO-03]**: Safely remove `AutopilotDispatcher` and `AutopilotEngine` internal core execution loops.

### 2. API Preservation
- **[AUTO-04]**: Maintain existing Autopilot GraphQL schemas and resolvers so the `ui-v1` front-end does not break.
- **[AUTO-05]**: Stub out GraphQL mutations temporarily so they return success or safe empty data without executing legacy internal logic.

---

## 📈 Out of Scope
- Re-architecting or rebuilding the new engine (this will happen in a future phase/milestone).
- Removing the Autopilot GraphQL schema or breaking the `ui-v1` application.

---

## 🔗 Traceability
- **Phase 21**: [AUTO-01, AUTO-02, AUTO-03, AUTO-04, AUTO-05]
