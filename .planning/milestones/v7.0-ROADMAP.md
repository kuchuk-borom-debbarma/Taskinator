# Roadmap: Milestone v7.0 (UI Alignment)

## Overview
Update `ui-v1` to align with the v6.0 backend Autopilot engine changes.

## Phases

### Phase 26: GraphQL Sync & Codegen
- **Goal:** Align backend GraphQL schema with v6.0 engine and generate updated TypeScript types in `ui-v1`.
- **Plans:** 2 plans
- [ ] 26-01-PLAN.md — Backend GQL Alignment (Recursive AST, Hydration)
- [ ] 26-02-PLAN.md — Frontend Sync & Component Fixes (Codegen)

### Phase 27: UI Autopilot Builder Updates
- **Goal:** Implement Dynamic Entity selection and Lazy-Context fields.
- **Tasks:**
  - Update `CreateAutopilotModal` and `Builder` to support Entity Type selection (Project/Task/Team).
  - Update `ConditionBuilderCanvas` to filter predicates by selected entity.
  - Update `ActionConfigForm` to support dynamic lazy-context field lookups.

### Phase 28: Pipeline Sequence Integration
- **Goal:** Update the Pipeline Editor to handle the new `PipelineStep` sequential array format.
- **Tasks:**
  - Refactor `ActionPipelineEditor` to support a unified list of Conditions and Actions.
  - Implement reordering logic for mixed-step pipelines.
  - Final integration test with the backend.
