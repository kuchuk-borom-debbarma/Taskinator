# Requirements - UI Integration for Autopilot
**Milestone:** v2.0-ui
**Date Completed:** 2026-05-15

## User Stories

| ID | Role | Story | Acceptance Criteria | Status |
|----|------|-------|---------------------|--------|
| US-01 | User | I want to see all my autopilots in a list | - Table/List view showing Name, Status (Active/Inactive), and Trigger types.<br>- Quick toggle for Active/Inactive state. | ✅ Validated |
| US-02 | User | I want to build conditions visually | - Use XYFlow to represent `AND/OR/NOT` nodes and `Predicate` nodes.<br>- Ability to add/remove/reconnect nodes.<br>- Real-time validation of the tree structure. | ✅ Validated |
| US-03 | User | I want to configure actions sequentially | - List view for actions with drag-to-reorder support.<br>- Predefined dropdowns for common fields (e.g., Task Status). | ✅ Validated |
| US-04 | User | I want custom values for action fields | - "Other..." option in dropdowns that reveals a text input field. | ✅ Validated |

## Technical Requirements

### UI-01: Visual Node Builder (XYFlow)
- **Status:** Complete
- **Goal:** Implement a node-based editor for `ConditionTree`.
- **Constraint:** Successfully serializes to/from depth-first backend JSON schema (`ConditionNode`).

### UI-02: Action Pipeline Editor
- **Status:** Complete
- **Goal:** Sequential list editor for `autopilot_action`.
- **Constraint:** Position-based list updates implemented and tied to backend array indexing.

### UI-03: GraphQL Mutations
- **Status:** Complete
- **Goal:** Wire the UI to the backend `createAutopilot` and `toggleAutopilot` mutations.
- **Constraint:** Executed via optimistic TanStack updates and secure Kysely database transactions.

### UI-04: Component Design
- **Status:** Complete
- **Goal:** Premium look and feel using Tailwind v4 and Framer Motion.
- **Constraint:** Integrated physics spring staggering and micro-transitions.
