# Milestone Requirements: v7.0 UI-v1 Autopilot Alignment

**Status:** ✅ SHIPPED 2026-05-17
**Milestone:** v7.0

## 📋 Requirements Checklist

### 1. GraphQL Integration
- [x] **GQL-01**: Align backend GraphQL schema and resolvers with the v6.0 engine (Recursive AST, Sequential Pipeline).
- [x] **GQL-02**: Run `codegen` to generate TypeScript types for v6.0 Autopilot entities in `ui-v1`.

### 2. Autopilot Builder (Dynamic Context)
- [x] **UI-CTX-01**: Dynamic Entity Selector in the Trigger configuration (Project, Task, Team).
- [x] **UI-CTX-02**: Entity-aware Condition Builder (context-aware predicate dropdowns).
- [x] **UI-CTX-03**: Lazy-Context Action Fields (lookup properties relative to the trigger entity).

### 3. Pipeline Editor (Sequential Array)
- [x] **UI-PIPE-01**: Update the Action Pipeline Editor to support a unified sequence of `PipelineStep` (mixing conditions and actions).
- [x] **UI-PIPE-02**: Support reordering of conditions and actions within the same pipeline list.
- [x] **UI-PIPE-03**: Enforce strict sequential semantics in the UI (halt on false condition visualization).

## 🚫 Out of Scope
- **OOS-01**: Node-based/Graph-based Pipeline Editor (retaining current list view).
- **OOS-02**: Client-side execution logs or loop detection visualization (server logs only).
- **OOS-03**: External service integration (Slack/Discord) for this milestone.
