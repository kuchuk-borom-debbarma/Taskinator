### Phase 40: Intra-Module Listener Decoupling
- **Goal:** Extract raw SQL from listeners into the `queries/` layer within the same module.
- **Tasks:**
  - Audit `auth`, `project`, `task`, `team` listeners.
  - Move logic to `internal/queries/*.ts`.
  - Update listeners to use queries.

### Phase 41: Inter-Module Listener Service Delegation
- **Goal:** Enforce module boundaries by calling services instead of foreign tables.
- **Tasks:**
  - Identify cross-module updates in listeners.
  - Implement/Update service interfaces to support these updates.
  - Replace direct DB updates with service calls.
  - Remove `db` imports from listeners.
