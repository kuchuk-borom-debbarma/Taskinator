## 3. Structural Analysis

### Public API (`src/modules/auto-action/index.ts`)
The public API is now strictly controlled. It exposes:
- `AutoActionService` (Interface)
- `autoActionService` (Singleton instance)
- `init()` (Bootstrapper)
- Public Types and AST nodes.

Internal engines (`actionEngine`, `conditionEngine`, `contextEngine`) are no longer accessible from outside the module.

### Internal Organization
The `internal/` directory correctly reflects the functional split:
- **`engines/`**: The core "brains" (Registries and Evaluators).
- **`execution/`**: The orchestration logic (Executor, Template generation).
- **`queries/`**: Data access layer.
- **`service/`**: Business logic, validation, and Public Service implementation.
