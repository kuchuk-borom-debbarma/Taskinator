## Known Tech Debt / Gaps
- **Edge Rendering Collision**: In extremely wide trees, XYFlow nodes can overlap on automatic sequential position generation. Users must manually drag to space them out.
- **Manual Refresh for Parallel Changes**: Changes made via external REST clients won't stream in real-time onto the list view; users need to click "Retry Connection" or remount the page. This aligns with current spec scopes.
